# ELSEWHERE OS · 梦境玻璃 V1

一个运行在浏览器中的平行宇宙操作系统。纯 HTML/CSS/JavaScript，无需构建，无需后端。

## 功能

- 梦境玻璃桌面、动态光影、Dock 和应用快捷方式
- 窗口拖动、调整大小、置顶、最小化、最大化、关闭
- 记忆档案馆：解封虚构文明记录
- 异星天气：切换三颗星球的天气
- 量子终端：支持 help、whoami、date、echo、gravity、clear
- 造物实验室：随机生成艺术图案并导出 PNG
- 时间机器：调整虚拟时间与桌面光照
- 系统设置：切换色调并保存偏好

## 运行与部署

直接打开 `index.html` 即可运行。GitHub Pages 使用 `main` 分支根目录部署。

线上地址：https://manxisuo.github.io/elsewhere-os/
